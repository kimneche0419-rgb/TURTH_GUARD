### 1. 프로젝트 개요

| 항목 | 내용 |
|:---|:---|
| **프로젝트명** | Truth History SDK — 생성형 AI 한국사 왜곡·멀티미디어 위변조 통합 탐지 오픈소스 프레임워크 |
| **프로젝트 등록 URL** | https://github.com/kimneche0419-rgb/Thruth_History |
| **시연 영상** | https://youtu.be/OKxuDfXSYjQ |
| **프로젝트 소개** | 생성형 AI가 만든 한국 역사 할루시네이션(거짓 역사 정보)과 멀티미디어 위변조(딥페이크·AI 복제 음성·합성 이미지)를 텍스트·이미지·영상·오디오 4대 모듈로 **단일 SDK 통합 탐지**하고, 판정 근거를 설명 가능한(XAI) 리포트로 제공하는 오픈소스 가드레일 |
| **개발 배경 및 목적** | ① LLM의 한국사 할루시네이션 대량 생성·유포, ② 역사 인물 딥페이크·복제 음성·합성 사진 확산, ③ 기존 도구의 단일 기능 파편화로 텍스트·이미지·영상·오디오 교차 검증 불가 — 이 세 문제에 대응해 **자사 인프라에 임베딩 가능한 단일 규격 가드레일**을 최소 비용으로 제공 |
| **개발 환경** | Python 3.13(SDK·백엔드) · TypeScript/React(대시보드) · JS(크롬 확장) · FastAPI/OpenCV/NumPy/Pillow/Click/Rich · Vercel 서버리스 + 로컬 CLI 이원 배포 |
| **아키텍처** | 공통 규격 `AnalysisResult`(위험 점수·AI 확률·판정 근거)를 4대 분석기가 상속 구현, 지연 로딩으로 필요 모듈만 선택 설치. 텍스트는 내장 한국사연표 KB+외부 검색 증거+GPT-2 Perplexity+시대착오 탐지, 이미지는 ELA+FFT, 영상은 temporal jitter+안면 비대칭, 오디오는 MFCC/HNR+보이스피싱 패턴으로 각각 판정 |

### 2. 프로젝트 상세 내용

**핵심 기능 및 특장점**

1. **4대 탐지 모듈 단일 SDK 통합** — 하나의 규격(`AnalysisResult`)으로 텍스트·이미지·영상·오디오를 동일 API·CLI·리포트로 교차 검증
2. **내장 한국사 사료 지식베이스** — 국사편찬위원회 「한국사연표」 기반 사건 41건·인물 15명, 네트워크 없이 "사건/인물×연도" 즉시 대조(예: *"임진왜란 1920년"* → 상충 검출)
3. **설명 가능한 판정(XAI)** — 연표 상충·ELA 편차·FFT 스파이크·Jitter 지수·증거 URL 등 근거를 구조화 JSON으로 반환
4. **실시간 대응 계층** — 크롬 확장(ChatGPT/Claude/Gemini 실시간 배지), `th stream`(RTSP/웹캠 2초 청크 증분 분석), MCP 서버(LLM 에이전트 직접 연동)
5. **경량·저비용** — 무거운 모델 없이 규칙 기반 + 선택적 GPT-2로 검증 레이어 구축, Vercel 무료 티어로 즉시 배포(https://platy-rho.vercel.app)
6. **다각도 판별 리포트** — 텍스트 6각도(사료 정합성·연표 KB·AI 생성·선동성·출처·시대착오) 등 매체별 신호를 각도별 점수·3단계 판정으로 시각화, 미분석 각도는 '미판정'으로 제외해 오판 방지
7. **지정학적 역사 왜곡 불허 사유 + 쟁점 지도** — 영토·주권(독도·동해·간도·사할린), 동북공정, 강제동원·위안부, 6·25 발발 주체 등 6개 사유와 개념도(SVG)·공식 출처를 역사 콘텐츠 판정에 자동 첨부, 비역사 콘텐츠엔 자동 미표시
8. **서버리스 정밀 분석 + 노이즈 없는 확장** — Vercel에 Pillow+numpy 탑재로 클라우드에서도 ELA/FFT 정밀 판정, 광고·사이트 로고 자동 제외, 배지에서 원본 다운로드→로컬 CLI 정밀 검증 연계

**개발 과정**

| 단계 | 내용 |
|:---|:---|
| 1. 코어 설계 | 공통 DTO(`AnalysisResult`)·`BaseAnalyzer` 추상화, 지연 로딩 임포터로 선택 설치 구조 구현 |
| 2. 분석 엔진 | ELA/FFT, 히스토그램 기반 Jitter, 안면 비대칭, MFCC/HNR 알고리즘 및 가중치 스코어링 설계 |
| 3. 통합 환경 | FastAPI 게이트웨이·통합 CLI(`th`)·React 대시보드·Vercel 배포·크롬 확장(MV3)·stdio MCP 서버 구현 |
| 4. 실시간 계층 | 스트리밍 청크 분석기(증분 처리·조기 종료·최악 청크 보수 종합), OpenRouter 무료 LLM 심사 경로(키 없이도 독립 구동) |
| 5. 리포트 고도화 | 다각도 판별 엔진·지정학 사유·쟁점 지도 구현, 연표 상충 가중합 희석 방지 상한 적용(오판 결함 수정), 확장 UX 정비 |
| 6. 품질 관리 | Vercel 서버리스 정밀 이미지 분석, 헬스체크·백엔드 자동 전환, 단위 테스트 90개, 전 CLI·API·실브라우저 E2E 검증 |

### 4. 기대효과 및 활용 분야

**기대효과** — 거짓 역사 정보·위변조 콘텐츠를 생성·유포 단계에서 조기 차단, 통합 규격화·경량 설계로 검증 레이어 구축 비용 절감, XAI 근거 공개로 감사 가능한 검증 제공

**활용 분야** — 뉴스·언론(사료 교차 검증), 교육·출판(고증 오류 검증, 네트워크 없이도 동작), SNS·플랫폼(CI/REST/스트리밍 연동 실시간 모니터링), AI 에이전트 생태계(MCP·크롬 확장 가드레일)

### 5. 기타

**혁신성 및 차별성** — 한국사 특화 고증(연표 KB+시대착오+외부 증거)과 멀티미디어 위변조 탐지를 단일 SDK로 통합한 국내외 최초 사례. 오프라인 결정론 고증 계층 내장으로 API 키 없이 즉시 판정. 크롬 확장→CLI→REST→MCP 5개 채널에 동일 엔진 노출

**한계 및 로드맵** — 한계: 내장 KB 규모(41건·15명), 정량 벤치마크 미보유, ELA/주파수 오탐 저감 여지. 로드맵(`ROADMAP.md`): Phase 1 벤치마크·정확도 리포트 → Phase 2 공공데이터 직접 연동·KB 확대·VSCode 확장 → Phase 3 CI/CD·PyPI·크롬 웹스토어·영문화

**소감** — "한국사 할루시네이션"이라는 국내 특화 문제를 MCP·크롬 확장·SBOM 준수 등 글로벌 오픈소스 생태계와 접목. 테스트 90개·실브라우저 E2E 검증으로 데모 수준을 넘어선 품질 확보
