# Truth History SDK — 설계 문서 인덱스

**Truth History SDK**는 생성형 AI로 인한 **한국 역사 할루시네이션**(그럴듯하지만 거짓인 역사 정보 대량 생성)과 **멀티미디어 위변조**(역사 사진 합성, 딥페이크 페이스 스왑, AI 복제 음성) 리스크에 대응하기 위해, 텍스트 고증 검증 + 시청각 교차 검증 모델을 단일 SDK로 통합한 오픈소스 프레임워크입니다. 본 디렉터리는 모듈별 상세 구현 명세와 개발자 가이드를 제공합니다. 프로젝트 전체 개요는 [루트 README](../README.md)를 참고하세요.

## 핵심 특징 요약
- **4대 탐지 모듈 통합:** 텍스트 고증 검증 · ELA 이미지 합성 · 딥페이크 페이스 스왑 · AI 복제 음성을 단일 규격의 교차 검증으로 제공.
- **지연 로딩 모듈러 + Model Agnostic:** 필요한 모듈만 로드하며, 경량 로컬 추론 모델부터 외부 거대 모델/팩트체크 API까지 유연 교체.
- **설명 가능한 판정 근거(XAI):** ELA 편차/바운딩, FFT 주파수 스파이크, 안면 랜드마크 오프셋 등 판정 근거를 JSON 리포트로 명확히 반환.
- **경량 로컬 추론 + 외부 API 연동 혼합 설계:** 자체 검증 레이어 구축 비용을 80% 이상 절감.
- **MIT 라이선스:** 뉴스·교육·공공 시스템이 자사 인프라에 자유롭게 임베딩·확장하여 디지털 역사 주권을 수호.
